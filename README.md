# Persian Date Library

کتابخانه کار با تاریخ شمسی در جاوااسکریپت (سازگار با ES5)

## ویژگی‌ها
- تبدیل تاریخ میلادی به شمسی و بالعکس
- پشتیبانی از فرمت‌های مختلف نمایش تاریخ
- محاسبه سال‌های کبیسه شمسی
- اضافه کردن روز به تاریخ
- سازگار با مرورگرهای قدیمی (ES5)
